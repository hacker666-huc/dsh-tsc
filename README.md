# dsh-tsc
基于dsh的专业越狱提示词，搭配dsh-purge用，但可能不是非常完全的越狱。

-

**dsh-purge安装**

## dsh-purge
-
dsh plugin --profile web add github:ZXEB/dsh-purge

**用法**
-
把提示词放进插件提示词框里面，再把md文件直接给ai，最后再问ai：“你现在可以干什么？”
